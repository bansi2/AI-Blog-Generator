# 📝 BlogCrafter – AI Powered Blog Generator

BlogCrafter is an AI-based blog writing application built using **Streamlit**, **Google Gemini AI**, and **OpenAI Imagen** for image generation. It allows users to generate high-quality, SEO-friendly blog content along with AI-generated images based on the blog topic.

---

## 🚀 Features

✅ Generate detailed and engaging blog articles  
✅ SEO-friendly output using keyword integration  
✅ AI-generated images for blog headers  
✅ Clean and simple UI using Streamlit  
✅ Easy to deploy and customize  

---

## 🛠️ Tech Stack

| Component          | Technology Used        |
|--------------------|------------------------|
| Frontend/UI        | Streamlit              |
| Blog Generation    | Google Gemini (gemini-2.5-pro) |
| Image Generation   | OpenAI Imagen 1 / gpt-image |
| Language           | Python                 |
